# output draft

*The `output.md` file in a [[piece folder]]: the prose of the piece, which you always write yourself.*

No writing workflow drafts prose into it. The gatherers ([[sync-guide workflow|sync-guide]], [[interview workflow|interview]]) never read or write it, and the checkers only read it. That's why you can run any workflow on a piece in progress without it clashing with your draft, however you produced it: typed, dictated and then polished, or sparked by an elicit brainstorm.

## Frontmatter

```yaml
---
title: Hollin Lane community orchard
status: in progress
last_updated: 2026-09-20
---
```

## The workflows that touch it

- **Write into it, but only in a marked place:**
  - [[beats workflow|beats]] writes a [[beats block]] under a section heading, never the prose around it.
  - [[polish workflow|polish]] cleans up text inside a [[polish marker]], or the whole file if you confirm.
  - [[scribe workflow|scribe]] works inside a [[scribe marker]].
- **Read it and report:** [[gap-check workflow|gap-check]], [[sanity workflow|sanity]], [[diploma-ready workflow|diploma-ready]].

This `status` is the draft's own progress field. It has nothing to do with the `status` on [[gathered note|gathered notes]].
