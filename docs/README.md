# Docs

Documentation for the AI layer, in two kinds: design-time docs for writing workflows, and user docs for using them.

- **Design-time**, read when writing or revising a workflow:
  - [[PRINCIPLES]]: the invariants every workflow must hold. A workflow that breaks one is wrong.
  - [[PATTERNS]]: reusable shapes that have worked across several workflows, such as the rubric, the gatherer and the toolbox.
  - [[My AI commandments]]: the owner's personal rules for using AI, from which several principles descend.
- **User docs**, read when using the workflows:
  - [[writing/README|Writing workflows]]: the nine tools for taking a piece from brief to finished draft, with the concepts they share.
